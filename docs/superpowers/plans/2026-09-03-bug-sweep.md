## Constraints (binding on all waves)

- **Fleet conventions (rule 1-9)**: DTO = record, ApiResponse/PageResponse envelope, ApiPaths.*,
  max page size, storefront read / backoffice write, AuthenticatedUser.requireCurrent(),
  @Transactional + @SQLRestriction, ddl-auto=validate + Liquibase-only, ENV defaults + outbox retries.
- **TDD**: failing test → implement → green → commit. Per-batch commit.
- **Wire contract (post 341b7d2):** producer = single-encoded JSON-string via
  `KafkaMessagePublisher`; consumer = `StringDeserializer` + tolerant unwrap. Don't regress.
- **Outbox locks (post 61a46c7):** every relay claims via `PESSIMISTIC_WRITE + SKIP LOCKED`.
  Don't bypass.
- **@Audited / @SQLRestriction / @JdbcTypeCode CHAR** discipline: follow committed patterns.
- **Boot proofs:** every change that touches a `@Bean` factory (auto-config, conditional bean)
  must keep shippable jars (`./mvnw -pl <svc> clean package`, then `java -jar` smoke against
  Testcontainers or user infra).
- **No secret leaks** in `.env`, `.env.prod.example`, source.
