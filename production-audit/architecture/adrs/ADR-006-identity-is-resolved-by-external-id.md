# ADR-006: The platform user is resolved by the external identity, not the generated key

- Status: Accepted
- Context: `User.id` is generated by the persistence layer, while the token subject is
  the identity provider identifier. The controllers passed the token subject into
  lookups by the generated primary key, so the self-service profile and address
  surfaces could never resolve a row. The entity already carries a separate unique
  column for the identity provider identifier.
- Decision: Resolve the user by the identity provider identifier column and treat the
  generated primary key as an internal surrogate.
- Consequences: the self-service surfaces resolve correctly and the two identifier
  spaces stop being confused.
- Evidence: `auth-service/.../entity/User.java:29-32,63`,
  `auth-service/.../controller/UserController.java:36`.
